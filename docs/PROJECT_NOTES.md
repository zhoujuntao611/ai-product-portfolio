从分散的反馈到可执行的维护任务

群聊反馈容易缺少环境和复现步骤，维护者需要补齐问题、检查改动、确认测试。Oriel 将反馈整理、修复与验收串成同一流程，保留原消息、补丁和测试记录，支持逐项审查。

我的工作：定义从反馈整理到修复验收的产品流程，设计实现 Pico Runtime 与 PicoBench，建立原版复现、修复检查与干净重放的回归验收机制。

01

成员留在熟悉的群聊里

直接提问或描述问题。有效反馈由维护者通过 /issue 沉淀到固定 Gitee 仓库，关联原始消息，重复提交按来源去重。

02

修复任务有固定起点

维护者使用 /fix 触发任务，重新读取 Issue，锁定 Base Revision 和验收命令；同一 Issue 正在处理时，不重复启动修复。

03

进度与结果回到原问题

进度会回复到原来的飞书消息或话题。通过验证后提供候选补丁；失败或受阻时说明原因。

三个决定，控制任务从哪里开始、到哪里结束

维护者确认后再启动任务

普通成员可以反馈问题，创建 Issue 与修复由维护者明确触发。保留确认步骤，关联原消息并去重，避免把未核实的群聊直接变成仓库任务。

先复现，再在干净环境验修复

维护者配置定向回归后，先确认原版失败，再要求修复与干净重放均通过。常规验收继续保留，并核对检查前后的源码差异，确保候选补丁与验收代码一致。

让维护者拿到可审查的依据

通过时交付 CANDIDATE.md、补丁、变更文件、退出码与日志；失败或受阻则交付诊断。维护者可以检查改动与验收范围，再决定是否采纳。

修复回归：原版复现、修复检查与干净重放

维护者通过 regressionCommands 配置定向回归检查：原版须以约定退出码复现失败，修复后与干净重放后均须通过，同时保留常规验收。原版未复现或检查异常时停止修复，候选包分别记录三个阶段的命令、退出码与日志。未配置定向回归时沿用常规验收流程。

检查完成后，将源码差异与已导出的候选补丁对照；检查命令若改写候选源码，则拒绝交付。维护者结合目标断言与日志确认失败原因，并审查测试覆盖和补丁内容。

Schema Token 与任务验收的取舍

PicoBench 固定任务、模型、预算和 Verifier。Tool Disclosure 内部实验中，Schema Token 减少 92.89%，通过数从 24 降到 23，延迟上升。最终保留原方案，以任务验收结果和成本共同判断优化是否成立。

Skill 受控实验：48 个任务与人工激活

Runtime 侧的经验复用实验以版本管理、相关性选择、独立验证和失败回退约束候选 Skill。内部固定任务集 A/B 覆盖 6 类能力、48 个未见及干扰任务，通过数由 15/48 到 24/48；该集合中原本成功的任务均保留通过。

为什么这样做

有引用，还要核对它是否回答了问题

“付款后 7 天内申请退款”不能回答“多久能到账”。因此，我将申请期限与到账时间分开检查；缺少对应资料时，系统先提示补充信息或转人工，再由客服审核。

验证结果

26 项合成开发回归：14/26 → 26/26。冻结 v2.0 与修复后 v2.1 使用同一组输入，原先失败的 12 项同题复测通过。这组测试用于固定样例回归，两个模型相关用例采用模拟响应。

历史真实模型接入：16/24 → 24/24。2026-10-19 在固定构造场景中接入 DeepSeek，经同题修复后复测；修复后的规则流程也为 24/24。该组用于模型接入与已知场景回归。

为什么保留人工审核

资料可能缺失，客户问题也可能包含特殊情况。工具负责整理草稿和引用，审核者核对后决定如何使用；系统不自动向客户发送消息。

DeepSeek 接入与对照设置

历史实验共记录 44 次成功模型调用：修复前产品流程 7 次、修复后 13 次、同模型直接判定对照 24 次。部分任务由规则直接分流，场景数与调用数分别记录。

主要功能

导入前检查数据

检查日期、金额、重复行和空值。有问题时，由用户确认处理方式。

常用订单分析

查看收入、订单数、渠道比较，以及退款金额和退款订单占比。

结果可以核对

报告保留筛选条件和原始数据行，支持导出 Markdown 和 JSON。

为什么这样做

退款统计先确认日期归属

同一张九笔订单示例表，二月退款按订单日算为 30 元，按退款发生日算为 120 元。两种口径回答不同问题；当提问与界面选择冲突时，我选择暂停查询、先确认条件，报告再保留原始行号与计算依据。

条件冲突时先确认

当问题要求按退款日期，而界面选择按订单日期，系统会暂停分析，提示用户调整条件后再生成报告。

如何检查计算结果

用可以手算的示例订单核对结果，并保留三版修改记录。同组 22 项已知输入测试全部通过，结果用于验证固定测试集中的计算与流程回归。
