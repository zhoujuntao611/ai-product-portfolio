先让资料可用、可维护。

导入带来源、地区、版本和有效期的知识；用同义表达与逐问题 BM25 检索。政策更新后拦截旧稿，避免旧依据继续进入审核。

CASE 02数据分析 / 只读工具

MetricPilot业务数据分析助手

让每一个数字，

先把自己的订单表变成可分析的数据。

预览订单 CSV、映射字段并检查数据质量，确认退款按原订单日还是发生日统计。问题与确认口径冲突时暂停查询，由用户统一。
