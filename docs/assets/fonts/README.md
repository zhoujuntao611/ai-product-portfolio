# Local portfolio fonts

Noto Sans SC and Noto Serif SC, provided by Google / The Noto Project and Adobe.

Upstream sources:
- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notoserifsc

License: SIL Open Font License 1.1. Complete upstream license notices are included beside the font files.

These WOFF2 files subset characters used in the homepage, project case and case dialogs, plus basic Latin. The site requests weights 400 through 700. They are hosted in this repository and never require a runtime request to Google Fonts. When editing copy, regenerate the subsets from the official source TTFs with FontTools; characters outside the subset use the declared system fallback.
