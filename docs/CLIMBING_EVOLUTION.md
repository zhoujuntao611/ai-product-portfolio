# 攀岩项目的演进

更新于 2026-10-25。当前围绕攀迹开发训练记录、线路历史和视频回看。早期 ClimbAI 的公开介绍与浏览器演示已撤下，旧地址跳转到攀迹。

## 两个项目的区别

ClimbAI 探索训练计划和反馈调整：在目标、时间和器材条件下生成安排，由用户确认。攀迹聚焦到馆记录：这次爬了什么、卡在哪里，以及下次怎样找到对应视频。

两者有需求上的关联，但代码、数据和存储独立。攀迹使用原生微信小程序、TypeScript 和自己的存储设计，没有直接迁移 ClimbAI 的 React 与 FastAPI 代码，也没有合并账号或训练数据。

## 当前状态

攀迹仍是开发预览，手机验收和公开发布尚待完成。训练记录可以存云端，视频与关联信息保存在当前设备；换机或清理微信数据可能影响回看。

从训练计划转向现场记录，是开发范围的调整，不能据此认定新方向已经得到市场验证。两个项目都没有已验证的训练改善或持续使用结果。
