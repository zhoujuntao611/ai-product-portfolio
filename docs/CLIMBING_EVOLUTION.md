## 从训练计划到现场记录

ClimbAI 探索训练计划和反馈调整：在目标、时间和器材条件下生成安排，由用户确认。攀迹聚焦到馆记录：这次爬了什么、卡在哪里，以及下次怎样找到对应视频。

ClimbAI 采用 React 与 FastAPI；攀迹采用原生微信小程序与 TypeScript，并针对现场记录设计独立的数据与存储结构。
