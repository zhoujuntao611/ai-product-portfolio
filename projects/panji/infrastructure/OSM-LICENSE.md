# OpenStreetMap 岩馆资料

`gym-catalog-osm.json` 是独立的 OSM 适配数据集，按 ODbL 1.0 提供。

© OpenStreetMap contributors

- 许可全文：https://opendatacommons.org/licenses/odbl/1-0/
- 版权与署名：https://www.openstreetmap.org/copyright
- 上游导出：https://openclimbing.org/export

本项目在该独立数据集中筛选人工攀岩场所、规范城市字段、保留正面设施标签及来源 ID。快照日期不表示逐馆现场核实当前营业。

小程序“岩馆”页及使用 OSM 资料的详情页显示署名，并提供本文件对应完整适配 JSON 的导出。其他来源的门店资料、应用代码及私人训练记录不因此自动获得 ODbL 许可；不得将私人记录纳入公开导出。
