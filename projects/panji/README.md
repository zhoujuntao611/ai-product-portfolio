# 攀迹 · 攀岩训练与 AI 文字复盘

个人产品实践，AI 辅助开发，微信原生小程序开发预览。这个公开源码副本用于求职作品展示与代码评审，基于 2026-10-22 的 0.2.2 版本整理，不提供共享云端账号或长期公开体验入口。

我负责产品范围、使用流程、交互取舍、AI 输入输出约束、公共资料整理与验收，借助 AI 编程工具完成实现。产品价值假设是：让一次训练的记录，接到下一次训练的行动。尚未完成系统用户研究或用户效果验证。

## 产品范围

- 14 个原生页面，支持训练与逐次线路尝试、草稿恢复、连续记录、成长统计及导出。
- 显式关联线路项目，跨训练查看尝试和卡点；同名线路不会自动合并。
- 视频关联、训练详情直接播放、倍速、时间点备注及两段对照；单段上限 5 分钟/100 MB，视频及关联仅保存在当前微信设备。
- 规则摘要、手写复盘、云端 AI 文字复盘，以及经用户确认或修改后的下次目标和训练核对。
- 228 处场所、71 个城市/地区的部分岩馆资料快照，保留来源、别名和开放条件；不是实时营业数据库或全国完整收录。

AI 使用腾讯混元 hy3 做文字复盘。程序计算摘要和确定性事实，模型原样引用事实并提出谨慎假设、行动建议，经过结构、引用和固定事实校验。备注默认不发送，视频不发送给模型。当前没有视频动作识别、姿态评分、RAG 或模型微调。

## 本机运行

建议使用 Node.js 22 或更新的受支持版本及 npm。普通本机检查不依赖微信登录、真实云数据库或模型调用。

```sh
npm ci
npm run verify
```

`verify` 依次执行类型检查、174 项本地测试、构建和页面文件/事件绑定检查。生成的 `miniprogram/`、云函数 `index.js` 与 `artifacts/` 均被忽略。不要把生成目录当作原始源码提交。

安装微信开发者工具后，导入本项目根目录，选择生成的 `miniprogram/` 作为小程序目录。默认 `project.config.json` 使用 `touristappid`，云环境为空，可先调试本机记录。当前页面默认空数据，测试使用合成记录。

```sh
npm run doctor
```

如需检查原生 WXML/WXSS，先安装微信开发者工具，并将环境变量 `WECHAT_COMPILER_DIR` 设置为其中包含 `wcc`、`wcsc` 的 `wcc-exec` 目录，再运行：

```sh
npm run verify:wechat
```

该编译器由微信开发者工具提供，未随仓库分发；路径由使用者配置。可选的 `WECHAT_DEVTOOLS_CLI` 指向自己安装的 CLI。不同平台的工具结构可能不同。

## 自己的账号与云端环境

手机预览需要自己的微信小程序 AppID、开发者权限及工具登录。配置命令只在本地写入工程账号和忽略的 `panji.local.json`，不会部署或调用云端：

```sh
npm run configure -- <自己的AppID> [自己的云环境ID]
npm run build
```

配置会修改 `project.config.json`；对外分享前需将其 AppID 恢复为 `touristappid`，并保留本机账号文件在忽略范围内。

云端源码在 `cloudfunctions/panji/`；`panjiV2/` 保存新版运行时的依赖配置。构建脚本从同一份 TypeScript 业务源码生成两版入口，新版目标为 Node.js 20。需要部署时，在所选云函数目录自行安装对应依赖，并在自己的环境配置数据库、安全规则、索引、定时触发器及模型权限。`infrastructure/` 的规则是工程配置材料，仍需在自己的账号验证，不构成已完成隔离或发布验收的承诺。

公开副本不含原开发环境、云端初始化/远程变更脚本、密钥、临时二维码或预览登录资料。普通本机检查不安装云端 SDK，也不发起云端请求。

AI 默认关闭。启用免费模型适配器需要在**服务端**显式配置 `PANJI_AI_ENABLED=true`、`PANJI_AI_BACKEND=cloudbase-free` 和 `PANJI_FREE_ENV_ID=<自己的环境ID>`；缺失或格式无效则关闭。不要把这些值放进客户端。调用前仍核对免费套餐、关闭超额和自动续费、模型单价及限额；平台和套餐是否满足条件需由部署者自行核对。每日 3 次、环境每月 30 次模型尝试包含失败尝试，没有自动付费回退。
