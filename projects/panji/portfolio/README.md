# 攀迹求职作品集

面向 AI 产品经理岗位的项目材料，整理于 2026-10-22。材料围绕**需求判断、流程设计、方案取舍与体验迭代**展开，当前小程序为开发预览。

本项目现已同步到[个人主页](https://zhoujuntao611.github.io/ai-product-portfolio/)、[攀迹产品案例](https://zhoujuntao611.github.io/ai-product-portfolio/panji/)及 [GitHub 公开源码](https://github.com/zhoujuntao611/ai-product-portfolio/tree/main/projects/panji)。最新一页 AIPM 简历与可编辑版位于求职材料导航，攀迹排在首位，保留 SupportFlow 和 MetricPilot；小程序本身仍为开发预览。

建议先用简历中的三条描述吸引阅读，再用个人主页解释关键决策，面试时打开界面和证据说明。

## 可以直接使用的材料

1. [项目总结](01_项目总结.md)：项目做了什么、个人承担什么、做过哪些取舍。
2. [AIPM 简历文案](02_AIPM简历文案.md)：标准版和短版，以及技能栏的写法。
3. [个人主页项目案例](03_个人主页项目案例.md)：项目卡片和可发布的长案例。
4. [面试讲述与证据](04_面试讲述与证据.md)：90 秒介绍、常见追问和下一轮验证方案。
5. [界面素材说明](素材/说明.md)：四张界面图的内容、版本和使用范围。
6. [验证摘要](证据摘要.json)：从已有验收报告整理的数量与边界，没有开发环境标识或用户记录。

## 使用顺序

简历建议使用标准版标题和三条要点；篇幅紧张用短版。个人主页可先放项目卡片，再放完整案例和两张界面图。讲述重点依次是：为什么做、如何形成闭环、AI 负责什么、真实反馈怎样改变设计、还有什么需要验证。

四张界面图来自开发者工具；训练和线路内容是合成数据。彩条画面是验收用合成视频，不能当作攀岩动作识别演示。当前没有可长期公开访问的体验地址，未将过期二维码和开发登录资料放入材料包。

## 数字怎么解释

228 指公共名录中收录的场所，包含岩馆及少量人工攀登训练设施；71 指城市/地区，不能解释成用户覆盖。176 项是自动化检查，14 页是微信原生编译范围；真实模型验证是 3 类合成场景及 7 项开发检查，不能写成用户测试或建议有效率。

以上是已有记录的整理，本次没有重新跑模型、云端数据流程或完整功能验收。尚未完成公开发布、完整手机验收及用户效果验证。后续如有真实用户研究，应补上招募、任务、样本和时间范围，再更新结果描述。
