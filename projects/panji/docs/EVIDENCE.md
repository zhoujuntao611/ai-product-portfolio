## 视频入口的交互调整

开发过程中的手机操作反馈指出，回看视频需要多次页面跳转。因此将播放入口移到对应的尝试卡片，并将慢放、时间点标记和双视频对照保留在视频工具中。

## 公开副本适配

1. `project.config.json` 使用 `touristappid`；客户端云环境保持为空。
2. `cloudfunctions/panji/ai-free.ts` 读取服务端 `PANJI_FREE_ENV_ID`。环境缺失或格式无效时关闭免费模型能力，计费校验要求匹配部署者明确配置的环境。对应测试在测试进程内设置合成环境，并使用模拟 SDK。
3. `doctor.mjs` 与 `wechat-compile.mjs` 通过环境变量及系统安装位置查找工具。
4. `build.mjs` 在首次构建时自动创建 `artifacts/`；两版云函数均将 SDK 作为运行时依赖，生成文件统一忽略。
5. 公开脚本覆盖本机构建、检查、账号本地配置和公共名录更新。云初始化、远程变更、真实模型验收、相册验收、扫码与演示录制脚本保留在原开发项目。
6. 原始 `artifacts/`、`panji.local.json`、`project.private.config.json`、`.env`、依赖目录和云函数生成入口按忽略配置排除。作品集文字与精选图位于 `portfolio/`。

公开名录保留来源链接、场所名称、公共地址和经纬度。OSM 适配子集保留独立的 ODbL 许可、署名与导出约定，其他资料遵循各自来源条款。
