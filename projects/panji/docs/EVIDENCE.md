公开版保留 174 项本地测试。原项目 176 项中的 2 项用于私人临时云初始化处理器；该处理器、调用脚本及对应 `provisioning.test.ts` 一同排除。两组数字对应不同范围，不互相替代，也不相加。

普通 `npm run verify` 使用合成数据、模拟 SDK 和本地文件，不调用用户数据库或真实模型。通过这些检查只说明相应规则、适配器和页面结构在检查环境内可运行。

## 仅在公开副本中的适配

1. `project.config.json` 使用 `touristappid`；客户端云环境保持为空。
2. `cloudfunctions/panji/ai-free.ts` 移除原环境常量，读取服务端 `PANJI_FREE_ENV_ID`。环境缺失或格式无效时关闭免费模型能力，计费校验仍要求匹配部署者明确配置的环境。对应测试仅在测试进程内设置合成环境，并使用模拟 SDK。
3. `doctor.mjs` 与 `wechat-compile.mjs` 移除作者机器路径，改用使用者配置的环境变量及系统安装位置。
4. `build.mjs` 在首次构建时自动创建 `artifacts/`；两版云函数均将 SDK 作为运行时依赖，避免本机构建依赖已安装的云端模块；生成文件统一忽略。
5. 仅保留本机构建、检查、账号本地配置和公共名录更新脚本；不包含云初始化、远程变更、真实模型验收、相册验收、扫码与演示录制脚本。
6. 原始 `artifacts/`、`panji.local.json`、`project.private.config.json`、`.env`、依赖目录和云函数生成入口不进入分享范围。作品集文字与精选图保留在 `portfolio/`，图片相对路径不变。

公开名录的来源链接、场所名称、公共地址和经纬度仍保留。OSM 适配子集的第三方许可和独立导出约定保留，不将其他数据统一声明为 MIT 或 ODbL。
