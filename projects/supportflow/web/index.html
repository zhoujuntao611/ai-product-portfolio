关于这个原型

本机运行，使用合成政策；没有接入真实客服渠道。

资料与版本

结构化 JSON 导入、必填字段校验、地区与生效时间筛选、新版本替换、停用与历史回看，避免旧政策继续参与当前回复。

条款检索与检查

从问题检索政策、检查适用条件，展示每条回复的原文、来源与版本。多问题同时检查覆盖情况；需要补充信息或人工判断时给出下一步。

审核记录

保留人工编辑和处理轨迹，按来源不适用、遗漏条件、回答不完整等原因标记问题，并导出脱敏样例用于下一轮评测。

评测与模型模式

固定合成问题集保留原关键词方案与改进方案的逐题结果。真实模型沿用现有证据选择接口；未配置密钥时使用规则模式，模型效果与业务收益尚未测量。

内置资料为合成政策。适合本机验证；不执行账户、资金或消息发送操作。

版本历史

历史版本仅供回看。当前检索使用最新且满足生效条件的资料。
