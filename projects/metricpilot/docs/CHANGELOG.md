## v2 · 2026-10-18

**从固定合成订单演示升级为用户订单 CSV 分析工具。**

- 新增 CSV 上传、前 12 行预览、字段建议与手动映射；明确日期格式、金额单位及币种。
- 新增重复、缺失、非法日期/金额、退款关系、币种和结构校验；数据处理由用户选择并保留行号。
- 将退款金额、净收入和退款占比改为能力驱动；未提供退款字段时保持未知，显式确认无退款后才使用 0。
- 新增退款日期归属与取消状态契约，区分订单队列口径和退款发生日口径。
- 聚焦收入概览、渠道比较与退款分析；支持两个明确期间比较。
- 使用 `query_orders` 受约束只读工具，移除当前服务的任意 SQL 路由 `/api/sql`。
- 报告增加源文件哈希、源行号、字段映射和处理决定；结论关联本次查询及原始结果，可导出 Markdown/JSON。
- 增加独立 9 单验收夹具、异常 CSV、含糊问题和业务边界测试。实际结果见 [eval_report.json](eval_report.json)。
- 旧合成数据及模型协议代码迁移到 `legacy.py`，只用于离线回归。v2 不调用外部模型，外部模型费用为 0。

### 失败到修复的证据

本次验收发现并修复：显式渠道未进入筛选；两种退款分母被合并；不支持的分母被替换；“1 月至 3 月”被误当为两个月比较；工具接受了未约定的日期格式。

首次失败输出保存在 [v2-adversarial-first-run.txt](../verification/v2-adversarial-first-run.txt)，修复后的同组运行保存在 [v2-adversarial-after.txt](../verification/v2-adversarial-after.txt)。另保留 UTF-8 结构化 [解析修复前](../verification/v2-parser-before.json) / [修复后](../verification/v2-parser-after.json) 四问快照，便于比较计划、状态、查询数与金额。

修复将明确渠道纳入筛选和一致性检查；多分母、未支持分母及期间范围歧义先澄清；工具直接校验约定日期格式。最终全量结果见 [评测报告](eval_report.json)。

浏览器首次验收另发现“比较各渠道净收入”被误判成渠道名，修复后可生成正确渠道汇总。保留 [浏览器首次运行](../verification/browser-first-run.json) 与 [最终浏览器验收](../verification/browser-qa-v2.json)，覆盖实际上传、选项变更、引用展开、报告下载、390px 窄屏和异常 CSV。
