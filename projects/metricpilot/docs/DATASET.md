# 数据集与口径

版本：`synthetic-v1`。数据为固定合成 SaaS 授权订单，覆盖 2026-01-01 至 2026-09-30。全部为合成数据，不代表真实经营记录或真实用户。

## 生成规则

从 2026-01-01 起第 `day` 天，按产品序号 `p = 0,1,2` 和渠道序号 `c = 0,1,2` 每个组合生成一笔订单。共 273 × 3 × 3 = 2,457 笔。

- `n = day × 9 + p × 3 + c`，订单 ID = `SYN-` + 五位 `n+1`。
- `quantity = 1 + (day + p × 2 + c) % 5`，表示授权席位数，不是订单笔数。
- Starter / Team / Enterprise 每席单价分别为 199 / 499 / 999 元。
- 毛收入 = 席位数 × 单价，以整数分存储。
- 当 `n % 13 = 0`，全额退款；否则当 `n % 29 = 0`，退款金额为毛收入的一半；其他订单不退款。
- 退款金额始终不超过订单毛收入。生成公式用于可重复验证，不模拟真实渠道分布、季节性、转化漏斗或客户生命周期。

## 业务定义

「订单数」为订单记录数；「授权席位数」为 quantity 合计，两个指标不能互换。毛收入为 quantity × unit_price_cents 合计；净收入为毛收入减 refund_cents。退款订单数为 refund_cents > 0 的订单记录数。

退款金额占比 = 退款金额 / 毛收入；退款订单占比 = 退款订单数 / 订单数。空范围的金额合计为零，分母为零的比率显示缺失，不显示为 0%。对比比率时使用百分点差；对比金额/计数时显示绝对差，基期非零才显示相对变化。

期间起止均包含当天。退款按原订单发生日归属。当前实现没有实际退款日期、折扣、税、获客成本或回款字段；因此净收入不应解释为利润、现金流或财务确认收入。

## 复核示例

2026 年 9 月共有 **270** 笔合成订单，净收入 **42,000,850 分（420,008.50 元）**。该数字已作为合成库的固定回归期待值；更关键的独立金额验证使用测试文件中手工指定的 4 笔订单，不使用生成器推导期待值。

运行 `python app.py` 首次建库；数据库不随重启改动。若主动修改数据库，测试中的合成库期待值仍使用临时新库；运行服务中的数字可能与这里不同。作品集交付库为原始 synthetic-v1。
