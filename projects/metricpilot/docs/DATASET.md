# 订单数据与导入协议 · v2

MetricPilot 使用用户上传的单张 UTF-8、逗号分隔 CSV；支持文件开头的 UTF-8 BOM。下载 [订单模板](../templates/orders-template.csv) 可直接体验导入。

## 支持的结构

每笔订单一行，标题唯一且非空，各记录与标题列数一致。文件限 2 MB、10,000 行、50 列。商品明细表、订单状态事件流和分次退款流水应先整理为一订单一行；同一订单存在不同记录时会阻断导入。

必需字段：

- `order_id`：唯一订单标识，保留原文。
- `order_date`：订单日期，按用户选定格式解析。
- `gross_amount`：该订单退款前总金额，不自动用单价或数量推导。

可选字段：

- `refund_amount`：订单累计退款金额，须非负且不高于订单金额。
- `refund_date`：该金额对应的单个退款归属日；存在正退款且映射本列时必须完整、合法且不早于订单日。
- `channel`：订单渠道，保留原文。
- `status`：订单状态，保留原文，用于精确识别取消状态。
- `currency`：币种代码；未提供此列时采用用户明确声明的币种。

字段名可不同，导入时确认映射。未被映射的列不参与指标计算；源文件指纹仍针对整份原始上传文本。

## 必须确认的解析规则

日期仅支持日粒度：`YYYY-MM-DD`、`YYYY/MM/DD`、`DD/MM/YYYY` 或 `MM/DD/YYYY`，分别选择 `iso`、`ymd_slash`、`dmy`、`mdy`。不猜测 `01/02/2026` 的月日顺序，也不自动截断时间戳。

金额单位选择 `major`（主单位）或 `minor`（最小单位）。CNY、USD、EUR、GBP 的主单位最多两位小数，内部乘 100 存储；JPY 主单位为整数，内部比例为 1。最小单位输入必须是整数。币种支持 CNY、USD、EUR、GBP、JPY。

不接受负数、科学计数、非有限数、千分位和货币符号；不自动四舍五入。币种列须与声明一致，多币种不自动换汇。单笔及汇总金额不得超过 9,007,199,254,740,991 个最小单位。

日期、金额和币种解析时移除首尾空白并显示说明；订单标识、渠道和状态保留原文。文件开头 BOM 的移除也会记入检查信息。

## 异常处理

所有检查在提交前展示。默认拒绝问题数据；用户可以明确选择：

- `duplicate_policy=drop_exact`：仅删除整行完全相同的后续重复行，保留第一行。
- `missing_refund=zero`：把已映射退款列中的空值视为 0。
- `missing_channel=unknown`：将已映射渠道列的空值标为“未标注”。
- `invalid_rows=exclude`：排除普通字段异常或空白记录。

冲突订单标识、多币种、不规则记录结构和金额越界仍需修正来源。排除、去重、填 0 和补渠道均保留相关行号及处理信息。

没有退款列时 `refund_cents=null`，`capabilities.refunds=false`，净收入和退款指标不可用。只有显式 `assume_no_refunds=true` 才把所有退款记为 0。没有渠道、状态或有效退款日期映射时，分别记录对应能力缺失。

## 归一化数据

内部每行包含 `order_id`、`order_date`、`gross_cents`、`refund_cents`、`refund_date`、`channel`、`status` 和 `source_row`。`*_cents` 是兼容旧版的字段名，实际表示声明币种的最小单位；须结合 `currency_scale` 解读。

数据集保留文件名、记录数、日期覆盖、渠道值、币种、金额单位、字段映射、处理决定、能力标识和 `source_hash`。`source_row` 是 CSV 记录起始的物理行号，标题通常为第 1 行；带引号的多行单元格按其起始行定位。

归一化订单保存在本机 `data/imports/`；原 CSV 不被改写。源文件 SHA-256 对原上传 UTF-8 文本计算，包含原始 BOM 和换行。复核时使用相同源 CSV、映射和处理决定。

## 验证夹具

[hand-check-orders.csv](../tests/fixtures/hand-check-orders.csv) 包含 9 笔手工订单，覆盖 2025-12-31 至 2026-03-01；这是独立验收夹具。金额与日期设置用于手算核对，示例见 [指标说明](METRICS.md)。

旧 `synthetic-v1` 数据生成器与产品表仅由 `legacy.py` 保留作离线回归；v2 工作台从导入数据生成查询，不自动载入旧合成数据库。
