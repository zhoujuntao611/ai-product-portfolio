# MetricPilot · 指标有据

面向 SaaS 运营分析的 AI 产品经理作品集项目。输入一个业务问题，确认指标和期间，执行只读统计，输出精确数字、查询引用、运行追踪和可导出的报告。

**本项目是新制作的个人演示作品。数据完全合成；没有真实企业上线、客户调研或外部大模型效果背书。** 默认使用明确标识的「演示规则引擎」，无需账户、密钥或依赖安装即可完整演示。真实模型模式是另行配置的工具调用接口，已用本地桩验证协议，尚未做外部服务实测。

## 一分钟启动

需要 Python 3.10+；实际验证环境为 Python 3.11.7。仅使用 Python 标准库、原生 HTML/CSS/JavaScript 和 SQLite，无需 npm 或 pip。

Windows：打开本项目目录，在 PowerShell 执行：

```powershell
python app.py
```

打开 <http://127.0.0.1:8766>。首次启动会自动建立合成数据库。保持终端运行，Ctrl+C 停止。

也可执行 `powershell -ExecutionPolicy Bypass -File .\launch.ps1`，启动隐藏的本机服务并打开浏览器。该方式会输出服务 PID，日志写入 `data/server.stdout.log` 和 `data/server.stderr.log`。若端口已由 MetricPilot 占用，则直接打开现有服务；若由其他程序占用则报错，不会终止别人的程序。

macOS / Linux：`python3 app.py`。更换端口：`python app.py --port 8866`。

## 三条演示路线

1. **渠道分析**：“2026年9月哪个渠道净收入最高？”→三个渠道比较→点击 Q1/Q2 引用→查看 SQL、参数、来源表、原始行→导出 Markdown 或 JSON。
2. **指标口径**：“2026年第三季度按产品比较退款金额占毛收入比例”→检查明确分母；再问“2026年9月退款率”→先澄清分母，不直接给出数字。
3. **月度比较**：“2026年9月对比2026年8月净收入变化”→对比两个明确期间→显示绝对变化及相对变化→提醒不能仅从收入推断原因。

侧栏可切换「数据与口径」和「分析记录」。筛选支持日期、产品、渠道和指标；问题中明确的期间优先，界面可复核最终识别期间。每次运行保留最近 40 次本机会话。

## 实现边界

- 演示规则引擎支持明确年月、季度、起止日期，以及产品/渠道/期间比较。一次选择一个主指标；不会声称具有通用自然语言理解能力。
- “最近”“9月”“2026年9月与8月”、含糊收入、含糊退款率会进入澄清。用户补充问题或明确筛选后重新运行；目前不是有记忆的多轮对话。
- 所有金额用整数分计算；净收入 = 毛收入 − 关联退款。退款归属原订单日，不是现金流水、利润或会计净营收。
- SQL 有 URI 只读连接、SQLite authorizer、表/函数白名单、参数绑定、单语句限制、200 行上限和约 250,000 虚拟机指令 / 1 秒预算。受系统调度影响，1 秒不是硬实时保证。
- HTTP 仅绑定 127.0.0.1；核验 Host；POST 要求匹配 Origin、CSRF token、JSON；拒绝分块请求；连接读取超时 10 秒。该服务用于本机作品演示，没有账户、租户隔离、审计平台或生产运维保障。
- 规则模式最终文本由查到的结果生成；模型模式同样由服务端根据工具结果生成数字。没有查询证据的模型文字不会成为分析结论。

## 可选：接入真实模型

支持提供 `/chat/completions` 且兼容 tools/function calling 的服务。在启动终端设置三个变量，密钥仅在服务端读取，请勿提交到仓库或展示在截图中。

```powershell
$env:METRICPILOT_BASE_URL = 'https://你的服务商地址/v1'
$env:METRICPILOT_MODEL = '你有权限的模型名'
$env:METRICPILOT_API_KEY = '你的密钥'
python app.py
```

在界面选择「真实模型」。BASE_URL 必须是 HTTPS，或本机 HTTP；禁止自动跟随重定向，防止向另一地址转发 Authorization。模型在已确认的日期/指标范围内调用 `query_sales(period_index, dimension)`；SQL 由受约束的统计工具生成，模型不能直接执行任意 SQL。最多 6 步，每次请求超时 25 秒，输出上限 2,048 tokens。中途失败不生成结论，也不会静默切回规则模式。

这是**受约束工具调用 Agent**，不是自由 Text-to-SQL、LangGraph 多 Agent 或 MCP Server。没有测试任意模型的兼容性、准确率或在线成本。选择此范围是为了保证数据口径、访问范围和答案可复核。

## 自动评测

```powershell
python evaluate.py
```

结果写入 `docs/eval_report.json`。报告数字来自实际 unittest 执行，包含每个案例的通过/失败状态；不是预置宣传数据。当前覆盖独立订单夹具的金额与分母、合成库边界、澄清、引用、SQL 攻击与资源限制、本地模型 HTTP 桩和本机 HTTP 访问校验。

这些是离线工程验证，不是用户满意度、真实模型任务成功率或收入提升。

## 文件导航

- `app.py`：合成库、意图澄清、指标查询、只读守卫、模型适配、报告、HTTP 服务。
- `static/`：响应式中文工作台；问答、筛选、图表、引用、追踪、原始数据、记录、导出。
- `tests/test_metricpilot.py`：独立数值、边界、安全和本地模型协议测试。
- `docs/PRD.md`：产品定位、待验证假设、MVP 取舍、状态、验收和埋点设计。
- `docs/EVALUATION.md`：评测方法及可复现的证据范围。
- `docs/DATASET.md`、`docs/schema.sql`：合成规则、字段和口径。
