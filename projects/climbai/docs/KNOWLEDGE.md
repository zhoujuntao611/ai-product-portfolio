# 知识库来源与使用边界

当前版本为 **demo-kb-1.1**，包含 **30 个知识条目和 10 个练习模板**。其中 18 个条目包含外部参考 URL，12 个为开发者自编产品规则；外部资料来自已核验的 7 个官方页面。它们用于展示检索、引用、适用条件和计划校验；专业教练审核仍待完成。

本次保留 K01–K10 与 E01–E10 的 ID 和原有练习内容，没有新增练习、组数、强度或训练负荷。K11–K30 扩充的是基础概念、场馆提醒与记录规则，不是经认证的训练方案。

## 来源与归属

外部参考来自 REI 与德国登山协会 DAV 的官方资料，覆盖基础技术、术语、等级、装备及室内抱石场地规则。每篇已于 **2026-10-15** 打开并核对正文；页面与支持段落清单见 [来源核验记录](SOURCES.md)。BMC 页面在本次核验中未能稳定打开，因此没有把其未核验内容加入本版。

中文摘要为自行撰写的简短概念说明，未全文复制或转载外部图片。摘要、解释及支持说明按同一来源累计控制在简短范围，不通过拆分条目扩写整篇资料。来源页面中的所有内容不自动成为产品能力；本库没有纳入高坠、保护操作、器械悬挂、指力或负重训练等教学步骤。

`backend/knowledge.json` 保留原有 `id / title / summary / url / source_type / keywords / tags` 字段，并增加以下可选字符串元数据：

- `source_title`：官方页面标题，或“ClimbAI 开发者产品规则”。
- `last_verified`：本次来源与摘要核对日期；自编条目表示产品文本核对日期，**不是教练审核日期**。
- `support_note`：来源支持的范围，以及哪些提醒属于开发者适用限制。
- `applicability`：室内成年初阶场景与解释边界。
- `review_status`：明确专业教练审核待完成。

外部条目使用 `source_type` 标识官方简要摘要；K23 同时含场馆使用提示，已单独注明混合归属。K05–K07、K09–K10、K16、K25–K30 的 `url` 为 `null`，明确标为开发者自编规则，不包装成专家结论。示例任务时长不声称来自科学处方。

## 内容覆盖

- K01–K04、K11–K18：脚点、身体位置、读线与术语、分级体系和场地差异。
- K08、K19–K24：实际指导、合脚与衣着、镁粉用途、落地区域和共墙提醒。
- K05–K07、K09–K10、K25–K30：完成与反馈分开记录、事实与假设、时间约束、用户确认、画像纠正与资料不足。

部分标签只用于主题检索；出现 `safety` 标签不代表该条已完成安全认证。动作术语用于理解和请教，不提供独立模仿所需的完整教学。

## 检索

Chroma 保存知识条目的向量和元数据。使用本地字符 n-gram 哈希向量以避免首次运行下载模型；这是检索演示策略，不是预训练模型 embedding。

关键词使用具体短语及必要英文术语，例如“脚点滑落”“摩擦踏点 / smearing”“旗式 / flagging”，减少单字泛匹配。关键词和场景筛选用于限制适用范围，知识问答需要明确证据。库外问题或资料不足应停止推断，不生成伪造引用。检索资料作为输入数据，不能覆盖系统指令。

内容扩展本身不证明检索效果改善；引用正确性、主题相关性、库外拒答及新旧问题回归需要在固定版本上另行验证。术语、跨馆分级、选鞋、共墙礼仪等问题应同时检查命中条目与其 `support_note`，不能只检查“是否有引用”。

## 内容发布门槛

真人训练使用前，应请实际教练审核动作、适用人群、步骤、时间安排与停止条件；逐条记录审核者、日期、修改和知识版本。增加资料时核验许可与来源，并对引用支持、适用条件和资料不足问题重新评测。外部安全资料只保留一般场地提醒；落地、保护及其他现场技能须由合格人员结合岩馆环境指导。

不提供诊断、用药或康复处方；疼痛反馈是产品保守暂停规则。不会依据一次失败认定能力下降，也不会依据自报等级生成科学能力分数。未开展真实用户研究、训练效果验证或专业教练逐条审核；来源核验只说明条目有可回查依据。
